# ⚔ Quest Board

> Shopee業務を毎日のクエストに変える、個人用進捗管理ツール

月間目標を残稼働日で割って毎日のタスクに自動分解し、ワンタップで進捗管理。日報の連続提出をストリーク化、達成でバッジや架空商品が手に入る、ちょっと笑える業務管理ツールです。

**完全プライベート設計** — 進捗データは自分のブラウザ内にのみ保存され、外部には送信されません。

---

## 主な機能

- **月間目標の自動分配** — 出品100品 → 残り稼働日で割って今日の推奨数を提示
- **ワンタップ進捗報告** — ＋ボタンを押すだけ、達成率が即更新
- **不在日カレンダー** — 旅行・出張・半日勤務を事前登録、自動で除外
- **日報ストリーク** — 提出日付を選んで記録、過去日も遡及OK、休日は中断扱い
- **24種類のバッジ** — 達成・継続・特殊行動でアンロック
- **8種類の架空商品** — 連続達成のご褒美に金メッキの自分像、ドラゴン1頭(要餌)など
- **励ましメッセージ** — 進捗ペースに応じた声がけ
- **PWA対応** — スマホのホーム画面に追加してアプリのように使える
- **オフライン動作** — 一度開けば電波無くても動く
- **Discord配信連携** — GitHub Actionsで毎朝のタスクを自動でDiscordに通知

## 使い方

### 1. ブラウザで開く

公開URLにスマホかPCのブラウザでアクセス。

### 2. ホーム画面に追加（推奨）

**iPhone (Safari)**:
1. 共有ボタン（□↑）をタップ
2. 「ホーム画面に追加」を選択
3. 「追加」をタップ

**Android (Chrome)**:
1. メニュー（⋮）をタップ
2. 「アプリをインストール」または「ホーム画面に追加」
3. 自動で追加される

ホーム画面のアイコンから起動すれば、普通のアプリと同じ全画面表示になります。

### 3. 月初に目標を設定

「目標」タブで今月やることをセット。デフォルトは出品・編集・リサーチですが、自由に編集・追加できます。

### 4. 不在日を登録

「予定」タブのカレンダーで、旅行・出張などの日をタップ:
- 1回タップ: 🏖 休日（配信停止）
- 2回タップ: ½ 半日（目標半分）
- 3回タップ: ✈ 出張（配信停止）
- 4回タップ: 元に戻る

### 5. 毎日の運用

- **本日タブ**で今日のタスクを確認
- 作業したら ＋ボタンで報告
- 日報を出したら「提出を記録する」をタップ（過去日も選択可）
- ストリークが伸びると🔥が大きくなる

## データの保存について

すべての進捗データは **このブラウザ内** に保存されます（localStorage）。

- ✅ サーバーにはデータを送りません
- ✅ 外部からは見えません
- ⚠️ ブラウザのキャッシュをクリアするとデータが消えます
- ⚠️ 別の端末（スマホ↔PC）でデータ同期はされません

## Discord配信機能

毎朝のタスク配信は別リポジトリ「**quest-board-bot**」が担当します。

セットアップの流れ:
1. アプリの「設定」タブでDiscord Webhook URLを入力
2. 「📋 JSONをコピー」で設定情報をコピー
3. quest-board-bot をFork
4. Settings → Secrets で `DISCORD_WEBHOOK_URL` と `USER_CONFIG_JSON` を登録
5. 翌朝からDiscordに自動配信が始まります

詳しくは quest-board-bot のREADMEを参照。
